# Idiomas (i18n) — plan y avance

Pedido del dueño (2026-11-02): la app debe mostrarse en el idioma del navegador.
Rama: `feat/i18n` (sobre `main` 6228d2b, v1.1). Este archivo es el punto de retorno si el trabajo se corta: **marcar cada casilla al terminarla y hacer commit + push a `feat/i18n`**.

## Decisiones
- Idiomas: **español (`es`)** y **inglés (`en`)**. El español sigue siendo el idioma de referencia (textos actuales).
- Detección: `navigator.languages` → el primero que empiece por `es` o `en`; si ninguno coincide, **inglés**. Selector manual en el menú (Español / English / Automático), guardado en `localStorage` (`escaque:lang`, con try/catch).
- Sin dependencias: módulo propio `src/i18n/` con diccionarios `es.js` y `en.js`, `t(key, vars)`, plurales con `Intl.PluralRules`, números, duraciones y fechas con `Intl`. Contexto React (`I18nProvider`, `useI18n`) y `t` también usable fuera de React (plantillas del coach, mensajes de importación).
- `<html lang>` se actualiza al idioma activo.
- Notación de jugadas: SAN en inglés en ambos idiomas (decisión vigente del dueño).
- Coach: las plantillas (`src/coach/templates.js`) y las voces de los 3 coaches existen en ambos idiomas. Con IA, el `CoachRequest` lleva `locale` y el system prompt pide responder en ese idioma (prompt en inglés para `en`, o instrucción explícita); la validación anti-alucinación no cambia.
- Rivales: las 390 frases (`src/rivals/personalities.js`) existen en ambos idiomas, adaptadas (no traducción literal) y con la misma personalidad.
- Nombres propios (Escaque, Alfred, Kairós, Ariadna, rivales griegos) no se traducen; los lemas sí.
- Una prueba automática verifica que `es` y `en` tienen exactamente las mismas claves y las mismas variables `{…}` en cada texto.
